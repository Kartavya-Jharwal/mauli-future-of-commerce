# Coursework prototypes

Place each runnable prototype in its own folder with a README explaining its hypothesis, audience, setup, demonstration path, assumptions and limitations. A prototype with package tooling should have its own `package.json`.

Possible future experiments include dosha discovery and recommendations, a Kautuka-inspired motion hook and a voice apothecary interaction. None is implemented or validated by this foundation. Avoid collecting real customer data in coursework demonstrations.
