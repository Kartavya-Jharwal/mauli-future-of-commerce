# Project showcase

This workspace currently contains the public-site scope and editable content manifest. It is not a built or deployed website.

The initial release is an in-progress case study. See [site scope](../../docs/website/site-scope.md) and [motion integration](../../docs/website/motion-integration.md). The custom splash and body SVG effect will be supplied separately. All seven team members use placeholders for now, as requested.

`content/project.json` is the implementation handoff: ordered sections, actual deliverable availability, future feedback/grade states and team placeholders. The visual build must resolve available source paths through a build step, expose only valid download URLs, and preserve pending states honestly.
